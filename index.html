LinkMap

A private map workspace for planning feeding routes, locations, supplies, and shared field work.

About LinkMap

LinkMap is a purpose-built iOS app for organizing homeless feeding activity around private map workspaces. It helps planners define service areas, maintain reusable locations and items, and prepare project routes with practical field details.

The released app centers work around owner-created workspaces. Each workspace can contain regions, layers, locations, reusable supply items, projects, assignments, routes, route stops, supplies, and distribution records.

Workspace data is stored in the user's private iCloud database and can be shared with collaborators through CloudKit sharing when collaboration is needed.

Core Features

Workspace Maps

Create private workspaces that organize service geography into regions, layers, and reusable locations.

Project Planning

Build project cycles with assignments, routes, ordered route stops, supplies, and distribution records.

Reusable Resources

Maintain shared workspace items and location records so each project can reuse established planning data.

CloudKit Sharing

Share owner-created workspaces with collaborators through iCloud while keeping workspace data private by default.

Planning Capabilities

Region & Layer Mapping

Model service areas with workspace-owned regions, vertical layers, and mapped location geometry.

Route Preparation

Plan route order, connect stops to reusable locations, and keep field work tied to the project map.

Supply Tracking

Assign reusable items to project teams and record distributions at each route stop.

Project History

Preserve completed or archived project records without changing reusable workspace resources.

Technology & Frameworks

Swift & SwiftUI

Modern, native iOS app built with Apple's latest frameworks for optimal performance and reliability.

MapKit

Native map integration for workspace regions, layers, locations, and route planning.

SwiftData

Efficient local app persistence for workspace lists, navigation state, and planning preferences.

CloudKit

Private and shared iCloud databases for owner-created workspaces and collaborator access.
