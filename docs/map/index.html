Map

The Project map is where LinkMap connects places, routes, selections, and activity logging.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • When the Map Appears
  • What the Map Shows
  • Activity and Assignment Pickers
  • Common Map Actions

Where to Find It

Open a Project, then switch to the Map tab. Project map tools are available from the map toolbar while the Project is active.

When the Map Appears

The Map tab is tied to the Project you currently have open. When no Project is open, Settings is shown instead. This keeps the map focused on one Project at a time.

What the Map Shows

  • Project Locations as markers or areas.
  • Region and Layer context for filtering the visible map content.
  • Selected Activity routes and stops.
  • Selected Assignment route focus when an Assignment is chosen.
  • Search results when you look for an external place.

Activity and Assignment Pickers

The Activity picker chooses which Activity's Routes, Stops, and logging context should appear. The Assignment picker narrows the view to one team or work group, making it easier to follow that Assignment's route and locations during active work.

Common Map Actions

  • Tap a Location marker to center it and open its actions.
  • Open Location detail when you need names, layer membership, photos, or other details.
  • Use edit mode to create a Location, move a Location, or edit Location areas.
  • Use Project map tools to manage Regions, Layers, Location membership, and map style.
  • Open the Activity Dashboard from the map when you need to log work near a Stop.
