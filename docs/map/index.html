Map

The Map is LinkMap’s launch screen and the main place to choose a work context, explore places, follow routes, and log activity.

LinkMap 3.0.0 Beta 8

This documentation describes the LinkMap iOS app.

Navigation Path

Map

When the Map Appears

The Map appears after launch and stays available even when no Project is selected. Without a Project, it shows the normal map without project-specific data. Settings remains a separate tab. Choose a Project through More (…) → Context to load its Locations and map resources. Regions, Layers, and Locations require a selected Project. Open More (…) → Context → Project, choose a Project, and tap Done before using these features.

What the Map Shows

  • Project Locations as markers or areas.
  • Region and Layer context for filtering the visible map content.
  • Selected Activity routes and stops.
  • Selected Assignment route focus when an Assignment is chosen.
  • Search results when you look for an external place.

Activity and Assignment Pickers

Open More (…) → Context for the Map Context sheet. Choose a Project first, an Activity within it, and optionally an Assignment, then tap Done. The Activity supplies Routes, Stops, and logging context; the Assignment focuses the visible routes and Locations on one team. Changing Project clears Activity and Assignment; changing Activity clears Assignment. Choose None to clear a selection.

Common Map Actions

  • Tap a Location marker to center it and open its actions. Choose Detail for its name, Layer membership, photos, and other details.
  • With a Project selected, use More (…) → Edit to create or move Locations. Save applies changes; Cancel discards them.
  • Open More (…) → Project Detail for Location List, Regions and Layers, route display options, and Refresh Map Data.
  • Use the map’s side selector to switch Layers and More (…) → Map Style to change the basemap.
  • Choose Dashboard in the Map toolbar to log work near a Stop after selecting the Activity in Context.
  • Use More (…) → Add Project to create a Project or Scan to join one with a collaboration QR code. Project Detail, Edit, and Dashboard require a selected Project.
