Logging and Reports

Logging captures what happened during an Activity. Reports turn the plan and results into reviewable text.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • Before Logging
  • Using the Activity Dashboard
  • Distributions
  • Reports After Work

Where to Find It

Open a Project, switch to the Map tab, select an Activity, then open the Activity Dashboard. Reports open from Assignment detail.

Before Logging

Logging works best after the Activity has Routes, Stops, Assignments, and Supplies. The dashboard uses that plan to understand which place and work context should receive the completed result.

Using the Activity Dashboard

  • Open the Project map and select the Activity you are running.
  • Choose an Assignment when you want to focus on one team or work group.
  • Open the dashboard from the Map toolbar near the Stop where work is happening.
  • Use the Stop picker when you need to switch the logging context.
  • Leave the dashboard with Done when the current logging pass is finished.

Distributions

A Distribution records the quantity of an Item completed at a Stop. Depending on the Project, that might mean delivered, installed, used, checked, handed out, collected, or otherwise completed.

Reports After Work

  • Open an Assignment report to review planned routes, supplies, and logged results.
  • Copy a report preview when the summary needs to be pasted into another app.
  • Edit the generated report when human wording matters.
  • Archive the Activity after the work and reports are complete enough to preserve as history.
