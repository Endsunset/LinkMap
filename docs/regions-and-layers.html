Regions and Layers

Regions and Layers make large or vertical maps understandable before you add Activity plans.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • Regions
  • Layers
  • How They Work Together
  • Editing Areas

Where to Find It

Open a Project, switch to the Map tab, then use the Project map tools to open Region and Layer management.

Regions

A Region is a broad area inside a Project map. Use Regions for buildings, zones, neighborhoods, halls, departments, service areas, or any large division that helps people understand where Locations belong.

Layers

A Layer is a level or surface inside a Region. Layers are useful when one area has multiple floors, stacked routes, indoor sections, or alternate map surfaces. Layer level 0 is reserved for the display-only Map row, so normal Layers should use other levels.

How They Work Together

  • Create a Region first when an area needs its own group of Layers or Locations.
  • Create Layers inside a Region when the same area needs multiple levels or surfaces.
  • Assign Locations to the matching Region and Layer so the map selector can focus the view.
  • Use Layer areas when a Layer should be shown as a polygon on the map.
  • Use layer ordering when the list of levels needs to match the real map structure.

Editing Areas

Layer area editing happens from the Map. You add vertices by tapping the map or reference vertices, remove target vertices when needed, and save when the shape is correct. Cancel restores the previous saved shape.
