Activities

An Activity is one planned cycle of work inside a Project.

LinkMap 3.0.0 Beta 8

This documentation describes the LinkMap iOS app.

On this page
  • Navigation Path
  • When to Create an Activity
  • What an Activity Contains
  • Using Previous Work
  • Active and Archived

Navigation Path

Map → More (…) → Project Detail → Activities

  • First select a Project in Map → More (…) → Context, then tap Done.

When to Create an Activity

Create an Activity when the Project is ready for a specific round of work: a delivery run, inspection, deployment, setup session, response shift, maintenance round, or any other bounded task cycle.

What an Activity Contains

  • Routes that describe where work should happen and in what order.
  • Stops created from Project Locations.
  • Assignments for people, teams, crews, vehicles, or work groups.
  • Supplies that describe what each Assignment should carry or prepare.
  • Logging and reports that capture what happened while the Activity was running.

Using Previous Work

When a new Activity is similar to an older one, you can use the previous structure as a starting point where the app offers that flow. This is useful for repeated routes, recurring assignments, or daily work that changes only slightly.

Active and Archived

  • Active Activities are still part of planning or execution.
  • Archived Activities are historical and kept for review.
  • Once an Activity is archived, activity-owned edits are no longer part of the normal workflow.
  • Archive after reports and logged results no longer need active changes.
