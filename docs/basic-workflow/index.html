Basic Workflow Example

This example follows one Project from setup through a completed Activity.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It

  • 2. Build the Map
  • 3. Add Items

Where to Find It

Open Settings, then Documentation, then Basic Workflow Example. Use this page as a first walkthrough before setting up a real Project.

1. Create the Project

Create a Project for the site or operation. For example, a campus supply run, an event venue, a neighborhood service area, or a field response zone. Once the Project opens, the Map tab becomes available for that Project.

2. Build the Map

  • Create Regions for broad areas, such as North Wing, Main Hall, Block A, or Service Zone 3.
  • Create Layers when the same Region has levels or surfaces, such as Floor 1, Floor 2, Basement, Roof, or Indoor Map.
  • Add Locations for entrances, rooms, supply points, delivery points, checkpoints, stations, or other places the team needs to visit.
  • Assign each Location to the correct Region and Layer so the map selector can filter the view cleanly.

3. Add Items

Add reusable Items before activity planning. If your team repeatedly works with water, kits, medicine, tools, printed materials, or equipment, create each one as an Item once. Later, Activities can use those Items as planned Supplies or logged Distributions.

4. Plan the Activity

  • Create an Activity for the specific work cycle, such as Morning Delivery, Day 1 Setup, Inspection Round, or Emergency Response.
  • Create Routes by choosing Project Locations and arranging the Stops in the order the team should visit them.
  • Create Assignments for people, teams, crews, or vehicles.
  • Add Supplies to each Assignment so the plan includes what each group should carry or prepare.
  • Link Routes to Assignments when each group should follow a particular route.

5. Run and Review

  • Open the Map while the Project is active and select the Activity you are running.
  • Use the Assignment picker when you want to focus on one team's route and locations.
  • Open the Activity Dashboard near the relevant Stop and log Distributions as work is completed.
  • Review the Assignment report after the Activity to summarize routes, supplies, and completed work.
  • Archive the Activity when it should become historical and no longer edited as active work.
