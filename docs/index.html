How LinkMap Works

LinkMap opens on the Map. Choose a Project to see shared places, then select an Activity and Assignment for the work you are doing.

Basic Workflow Example

This example follows one Project from setup through a completed Activity.

Project

Project

A Project is the top-level workspace. It contains the map, Items, Activities, collaboration, and work history.

Items

Items are the reusable resources a Project plans with and records during work.

Map

Map

The Map is LinkMap’s launch screen and the main place to choose a work context, explore places, follow routes, and log activity.

Regions and Layers

Regions and Layers make large or vertical maps understandable before you add Activity plans.

Locations

Locations are reusable places on the Project map. Activities use them later as route stops and logging points.

Activities

Activities

An Activity is one planned cycle of work inside a Project.

Routes and Stops

Routes turn Project Locations into an ordered plan. Stops are the individual places in that order.

Assignments and Supplies

Assignments define who does the work. Supplies define what they plan to carry, use, or deliver.

Logging and Reports

Logging captures what happened during an Activity. Reports turn the plan and results into reviewable text.

Collaboration

Sharing

Sharing lets other people open and work from the same Project.
