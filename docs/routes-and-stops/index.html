Routes and Stops

Routes turn Project Locations into an ordered plan. Stops are the individual places in that order.

LinkMap 3.0.0 Beta 8

This documentation describes the LinkMap iOS app.

On this page
  • Navigation Path
  • Building a Route
  • Stops
  • Routes on the Map
  • Good Route Planning

Navigation Path

Map → More (…) → Project Detail → Activities → Activity → Routes

  • First select a Project in Map → More (…) → Context, then tap Done.

Building a Route

  • Open an Activity, then create a Route from the Activity's route area.
  • Choose Locations from the Project map data.
  • Order the selected Locations in the sequence the team should follow.
  • Save the Route so its ordered Stops become available for map display and logging.

Stops

A Stop is one ordered destination in a Route. Stops are created from Locations, but they belong to the Activity's plan. This means the same Project Location can be reused in different Activities or different Routes without changing the original Location.

Routes on the Map

  • Selecting an Activity shows its route context on the Project map.
  • Selecting an Assignment can focus the map on routes linked to that Assignment.
  • Selecting a Stop gives the dashboard the right place to log work.
  • Route line geometry is shown for planning and navigation context while the saved plan remains based on ordered Stops.

Good Route Planning

Build Routes after Locations are reasonably organized. Clear Location names, Region membership, and Layer membership make it much easier to choose the right stops and avoid sending a team to the wrong place.
