Sharing

Sharing lets other people open and work from the same Project.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • When to Share
  • Invite Methods
  • Working Together
  • Ending Collaboration

Where to Find It

Open a Project detail page, then use the Project toolbar menu for collaboration links, QR codes, and sharing controls.

When to Share

Share a Project when collaborators need the same map, Items, Activities, Routes, Assignments, Supplies, and logged results. Sharing is Project-based, so collaborators join the whole Project rather than only one Activity.

Invite Methods

  • Start collaboration from the Project tools.
  • Use a LinkMap collaboration link when the invite should be sent through another app.
  • Use the QR code when collaborators are nearby and can scan from their device.
  • After accepting, collaborators see the shared Project in their Project list.

Working Together

  • Keep Project setup clear before a busy Activity so everyone sees the same map structure.
  • Use Activity and Assignment names that collaborators can recognize quickly.
  • Refresh lists when expecting newly shared or recently changed Project data.
  • Use reports when the team needs a readable summary outside the live map.

Ending Collaboration

When collaboration ends, shared access is removed. Collaborators stop seeing the Project after their Project list refreshes.
