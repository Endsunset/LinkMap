Locations

Locations are reusable places on the Project map. Activities use them later as route stops and logging points.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • What Counts as a Location
  • Ways to Add Locations
  • Editing Locations
  • How Activities Use Locations

Where to Find It

Open a Project, then use the Map tab or Project Location list. Location detail can also open from a Location marker on the Map.

What Counts as a Location

A Location can be a room, checkpoint, entrance, address, station, storage area, pickup point, delivery point, or any place the team needs to see on the map. Locations belong to the Project, so the same Location can be reused by many Activities.

Ways to Add Locations

  • Create a Location from the Project Location list.
  • Create a Location directly on the Map by entering map edit mode and tapping its position.
  • Upload local annotation data when prepared location data already exists outside LinkMap.
  • Add existing Project Locations to a Layer without creating duplicate places.

Editing Locations

  • Move a Location from the Map when its coordinate needs correction.
  • Edit a Location area when a place covers a polygon rather than a single point.
  • Set Region and Layer membership so map filtering stays accurate.
  • Detach a Location from a Layer when it should remain in the Project but no longer appear on that Layer.
  • Use photos where available to keep visual context with the place.

How Activities Use Locations

Routes are built from Project Locations. Each Location chosen for a Route becomes an ordered Stop for that Activity. When work is logged at a Stop, the Location gives the dashboard and report the place context.
