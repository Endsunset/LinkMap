Assignments and Supplies

Assignments define who does the work. Supplies define what they plan to carry, use, or deliver.

LinkMap 3.0.0 Beta 8

This documentation describes the LinkMap iOS app.

On this page
  • Navigation Path
  • Assignments
  • Linking Routes
  • Supplies
  • Reports

Navigation Path

  • Map → More (…) → Project Detail → Activities → Activity → Assignments
  • Map → More (…) → Project Detail → Activities → Activity → Supplies
  • First select a Project in Map → More (…) → Context, then tap Done.

Assignments

Use Assignments for people, teams, crews, vehicles, stations, or work groups. An Assignment gives the Activity a clear owner for part of the plan. It can be linked to Routes and can have Supplies attached to it.

Linking Routes

  • Create the Route that describes where the work should happen.
  • Create or open the Assignment responsible for that route.
  • Link the Route to the Assignment when the route belongs to that person or team.
  • Use Map → More (…) → Context → Assignment to focus on that Assignment’s route and Locations.

Supplies

Supplies are planned quantities of Project Items for an Assignment. If an Item is the reusable resource, a Supply is the amount one Assignment plans to carry, prepare, or use during this Activity.

Reports

  • Assignment reports use the Assignment's routes, supplies, and logged work as source material.
  • Preview reports before sharing them outside the app.
  • Edit report text when a generated report needs clearer final wording.
  • Report Style settings control generated report language separately from the app's interface language.
