Project

A Project is the top-level workspace. It contains the map, Items, Activities, collaboration, and work history.

This guide describes the LinkMap iOS app.

On this page
  • Where to Find It
  • What a Project Is For
  • What Goes Inside
  • How Project Navigation Works
  • Good Project Setup

Where to Find It

Open the Home tab to create, browse, or reopen Projects. After you open a Project detail page, the first tab is labeled Project, and the Map tab follows that Project.

What a Project Is For

Use a Project for one real-world place or operation that needs repeated planning. A Project can be private to you or shared with collaborators. It is the common base that keeps the map, resources, and Activity history together.

What Goes Inside

  • Map: the Regions, Layers, and Locations that describe where work happens.
  • Items: reusable resources that may be carried, delivered, used, or counted.
  • Activities: individual work cycles that use the Project map and Items.
  • Reports and history: completed Activity information that remains available for review.
  • Sharing: collaboration access for people working from the same Project.

How Project Navigation Works

  • The Home tab shows your available Projects and recent Project access, then becomes the Project tab while a Project is open.
  • Opening a Project shows its detail page and makes the Map tab follow that Project.
  • Project detail is the starting place for Activities and Items.
  • Map-building tools are available from the Map tab while the Project is open.

Good Project Setup

A useful Project usually starts with a clear name, a few Regions or Layers if the place is complex, the Locations the team will actually visit, and the Items the team will repeatedly plan or log. You can add more structure later as the Project becomes clearer.
