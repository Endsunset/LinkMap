# How LinkMap Works

A Project keeps your places together. An Activity plans one round of work using those places.

## Start on the Map

Open Dashboard → Context to choose a Project. You can also choose an Activity and, when one is available, an Assignment. Return to the Map to see the places and route for your current work.

Use Dashboard → Current Project to manage the Project. Add places before planning a Route. When you are ready to work, create an Activity, add a Route and Assignments, and select that Activity in Context.
