# Regions and Layers

Regions divide a Project into broad areas. Layers describe levels or surfaces within a Region, such as a floor or indoor map.

Assign Locations to the appropriate Region and Layer so the Map can filter them. The Layer selector appears when the map’s center is inside a Layer polygon and lists Layers for that Region. Project Detail contains the Region and Layer tools; map editing supports area vertices and Location membership.
