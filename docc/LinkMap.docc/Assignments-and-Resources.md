# Assignments and Resources

An Assignment represents a person, team, crew, or vehicle working in an Activity.

An Assignment can have Routes and hold Item quantities through Transactions. Select an Assignment in Map Context to focus its routes and Locations. The Activity supply workflow can move Items from Inventory to Activity, then from Activity to a selected Assignment. Resource balances are derived from the transaction ledger.
