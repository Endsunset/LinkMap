# Projects and Activities

A Project is the long-lived workspace for a map and repeated work. It owns reusable Regions, Layers, Locations, Items, and Inventory. An Activity is a shorter work cycle inside the Project, with its own Assignments, Routes, Stops, and resource history.

The iOS app creates and manages both. The web app reads the Projects and Locations available to the account. This division lets the same Project map support many Activities without duplicating its places.
