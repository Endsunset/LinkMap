# Basic Workflow Example

Follow one Project from setup through a completed Activity.

1. From the Map, open Dashboard → Add Project. Create the Project, then select it from Dashboard → Context.
2. Open Dashboard → Current Project. Add Regions, Layers, and Locations for the area where work will happen. Add reusable Items and an Inventory.
3. Create an Activity for this work cycle. Add Assignments for teams and Routes that use Project Locations as ordered Stops.
4. In the Activity supply workflow, move Items from Inventory into the Activity and then into Assignments. Transactions record these movements; balances are derived from them.
5. Select the Activity in Context. Follow its routes on the Map, use the Activity Dashboard for stop work, and review resource history and the Assignment report.
6. Archive the Activity when it becomes historical. Reuse the same Project map and Items for the next Activity.
