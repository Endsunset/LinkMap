# Collaboration

A Project is the unit of sharing. Its owner can invite collaborators to the same Project, including its map and active Activity data. A collaborator accepts a link or scans a QR code in the iOS app, then chooses the shared Project in Context.

The web app can read Projects that are available to the signed-in Apple Account, including accepted shared Projects. When access ends, the shared Project disappears after the available Project list refreshes.
