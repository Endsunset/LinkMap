# Activities

An Activity is one cycle of work within a Project.

Create an Activity after its Project foundation is ready. Assignments and Routes belong to that Activity; Routes contain ordered Stops that point to Project Locations. Resource movements can flow from Inventory to Activity and then among Activity, Assignment, and Stop anchors.

Archiving makes the Activity historical. The owner can archive it even when the Project is not actively shared. Archived Activity resource history remains readable.
