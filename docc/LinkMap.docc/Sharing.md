# Sharing

Sharing grants collaborators access to a whole Project and its active child records.

Start collaboration from Project tools and send a LinkMap collaboration link or show its QR code. A collaborator can open the link or use Dashboard → Scan, then refresh Projects and select the shared Project in Context. The Project is the CloudKit share root, so its map, resources, and Activities stay together.

After access is removed, the shared Project disappears from a collaborator’s refreshed Project list.
