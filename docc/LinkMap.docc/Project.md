# Project

A Project is the shared workspace and CloudKit share root for its map, Items, Inventory, Activities, and history.

Open Dashboard → Current Project after selecting a Project in Context. Projects can be private or shared with collaborators. A Project keeps reusable foundation records separate from shorter Activity cycles.

## Structure

- Regions and Layers organize the map.
- Locations describe places on that map.
- Items identify reusable resources; Inventory holds their balances through Transactions.
- Activities organize Assignments, Routes, Stops, and work history.
