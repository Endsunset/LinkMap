# Map

The Map is the iOS app’s launch screen and stays visible even when no Project is selected.

Use Dashboard → Context to select a Project, Activity, and Assignment. A selected Project loads its Locations. A selected Activity adds its Routes; an Assignment narrows markers and route overlays to that team’s work. The Map also offers place search and map style controls.

Tap a Location marker to open its actions, then choose Detail. Use Edit Locations from the Map toolbar’s ellipsis to add or move places. Map changes are saved explicitly; Cancel restores the last stored record.
