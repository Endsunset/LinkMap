# Locations

Locations are reusable Project places: entrances, rooms, checkpoints, stations, or delivery points.

Each Location has a coordinate and can reference a Region and Layer. A Location can also describe an area with vertices. Routes reuse Project Locations as Stops, so changes to the Project map can support later Activities.

From the Map, use Edit Locations to create or move a Location. Tap a marker and choose Detail to inspect it. Explicit Save persists edits through CloudKit; Cancel restores the stored values.
