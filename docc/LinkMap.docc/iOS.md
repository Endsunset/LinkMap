# LinkMap for iOS

Create Projects, map places, plan Activities, move resources, and collaborate in the iOS app.

The app opens on the Map. Use Dashboard to select Context, open the current Project, browse Projects, or open an Activity. Context selects a Project, then an Activity and optional Assignment. The Map toolbar’s ellipsis contains Edit Locations, Map Style, and Settings.
