# Routes and Stops

A Route orders the places to visit during an Activity. Each Stop refers to a Project Location.

Create a Route in the Activity, choose Project Locations, and arrange its Stops. A Route can be linked to an Assignment. Selecting an Activity or Assignment on the Map shows the relevant route overlay. Stop resource balances come from Transactions; the Route itself is navigation context, not a resource endpoint.
